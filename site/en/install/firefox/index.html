How to install Tabskin in Mozilla Firefox

Replace Firefox's default new tab with a calm page featuring Unsplash wallpapers.

  1. Open Firefox Add-ons

    Visit Tabskin on Mozilla Add-ons.

  2. Add to Firefox

    Click Add to Firefox and confirm.

  3. Open a new tab

    Tabskin replaces the default new tab page.

  4. Customize wallpapers

    Pick a theme in settings: nature, architecture, travel, and more.
