How to install Tabskin in Google Chrome

Replace the default new tab with a minimalist Unsplash wallpaper page in a couple of minutes.

  1. Open Chrome Web Store

    Visit the Tabskin Chrome Web Store page.

  2. Click Install

    Confirm the extension install. Chrome may ask permission to override the new tab page.

  3. Open a new tab

    Press Ctrl+T (Windows) or Cmd+T (Mac) to see Tabskin.

  4. Pick a wallpaper theme

    Open settings and choose a category: nature, architecture, travel, and more.
