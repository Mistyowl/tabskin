Privacy Policy

This policy describes how the Tabskin extension for Chrome, Firefox, and Edge handles user data.

Data collection and usage

Tabskin does not collect, store, or transmit personal user data. Settings are stored locally in your browser.

Unsplash download location

For Unsplash API compliance, Tabskin sends technical information about background image installation (download location). This contains no personal data.

Third-party sharing

The extension does not share personal data, use ad technologies, or add third-party trackers. Access is limited to Unsplash images.

Security

Tabskin operates within permissions required for its main function and does not request access to confidential information.
