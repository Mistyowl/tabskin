Как установить Tabskin в Google Chrome

Замените стандартную новую вкладку на минималистичную страницу с обоями Unsplash за пару минут.

Tabskin — бесплатное расширение для Chrome, которое показывает красивые обои, часы и локальные настройки без рекламы.

  1. Откройте Chrome Web Store

    Перейдите на страницу Tabskin в Chrome Web Store.

  2. Нажмите «Установить»

    Подтвердите установку расширения. Chrome может запросить разрешение на замену новой вкладки.

  3. Откройте новую вкладку

    Нажмите Ctrl+T (Windows) или Cmd+T (Mac). Вы увидите Tabskin с обоями и часами.

  4. Выберите тему обоев

    Откройте настройки расширения и выберите категорию обоев: природа, архитектура, путешествия и другие.
