Как установить Tabskin в Mozilla Firefox

Замените стандартную новую вкладку Firefox на спокойную страницу с обоями Unsplash.

  1. Откройте Firefox Add-ons

    Перейдите на страницу Tabskin в каталоге Mozilla.

  2. Добавьте расширение

    Нажмите «Добавить в Firefox» и подтвердите установку.

  3. Откройте новую вкладку

    Создайте новую вкладку — Tabskin заменит стандартную страницу.

  4. Настройте обои

    Выберите тему обоев в настройках: природа, архитектура, путешествия и другие категории.
