Политика конфиденциальности

Настоящая политика конфиденциальности описывает, как расширение Tabskin для браузера Google Chrome/Mozilla Firefox/Microsoft Edge обрабатывает пользовательские данные.

Сбор и использование данных

Tabskin не собирает, не хранит и не передаёт персональные данные пользователей. Настройки, включая язык интерфейса, формат времени, тему оформления и другие параметры, сохраняются локально в браузере пользователя и не покидают его устройство.

Download location Unsplash

Для корректной работы и соблюдения условий Unsplash API расширение Tabskin отправляет техническую информацию о факте установки фонового изображения (download location). Эта информация не содержит персональных данных и используется только для статистики, требуемой Unsplash.

Передача данных третьим лицам

Расширение не передаёт персональные данные третьим сторонам, не использует рекламные технологии и не добавляет сторонние трекеры. Доступ осуществляется только к изображениям Unsplash для отображения фонов новой вкладки.

Безопасность

Расширение работает в рамках разрешений, необходимых для своей основной функции, и не запрашивает доступ к конфиденциальной информации. Tabskin не взаимодействует с другими сайтами, за исключением загрузки изображений с Unsplash.

Используя расширение Tabskin, вы подтверждаете, что ознакомились с настоящей политикой конфиденциальности и соглашаетесь с её условиями.
